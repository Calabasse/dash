Prescription Tuning

Read-only view of the parameters the workout engine (prescribe_hypertrophy.py) uses. Deterministic algorithm — no AI.
This page displays the engine's current parameters. The config is owned upstream; this is a display-only copy refreshed here on every deploy.

Training philosophy

Global parameters

warm-up fracs = comma list of % of top load (one per warm-up set). backoff frac = backoff load as a fraction of top. step sizes = how much load is added when a set is "earned".

Per-movement parameters

movement typerep lorep hi anchortop RPE warmupsbackoffs isolation
anchor = reps you must hit on the top set before load goes up. top RPE = the intensity cap. Loads always snap to your real equipment (plates / bands) regardless of these.

Auto-tuned parameters

Read-only reflection of the live self-tuning loop's state (D-07): live value, ratified bounds, and lock status for each of the three parameters run_system_tuner() actually persists. Pinned values are set from a separate, local-only tool — this page has no write capability of any kind (D-08).

Recent tuning history

The most recent auto-tuning adjustments across all three parameters, newest first — the change history control_tuning_history has always recorded, now with a display surface.

Lock activity

Lock/unlock actions and suppressed auto-tuner writes, newest first. A suppressed row shows both the pinned value that was kept and the computed value that was discarded — the reason a locked parameter's value has stopped moving.

Declared but not auto-tuned

Present in the control schema, but never written by the live self-tuning loop — shown separately from the three auto-tuned parameters above precisely because it behaves differently from them.

Engine constants

Flat constants read from the engine's own config (not the calibration feed above) — no auto-calibration behavior exists for these. Where a value carries an explicit ratification record, it is marked.

Status

Values are read-only. The config is edited at its source and this page refreshes to show whatever the engine currently uses.
