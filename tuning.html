Prescription Tuning

Read-only view of the parameters the workout engine (prescribe_hypertrophy.py) uses. Deterministic algorithm — no AI.
This page displays the engine's current parameters. The config is owned upstream; this is a display-only copy refreshed here on every deploy.

Training philosophy

Global parameters

warm-up fracs = comma list of % of top load (one per warm-up set). backoff frac = backoff load as a fraction of top. step sizes = how much load is added when a set is "earned".

Per-movement parameters

movement typerep lorep hi anchortop RPE warmupsbackoffs isolation
anchor = reps you must hit on the top set before load goes up. top RPE = the intensity cap. Loads always snap to your real equipment (plates / bands) regardless of these.

Auto-tuned parameters

Read-only reflection of the live self-tuning loop's state (D-07). Pinned values are set from a separate, local-only tool — this page has no write capability of any kind (D-08).

Status

Values are read-only. The config is edited at its source and this page refreshes to show whatever the engine currently uses.
